# Elite Finish Auto — Website Changes (2026-06-03)

Summary of all updates made to the site during this session. Most work was on
`index.html` (home page) and `styles.css`, with some changes applied across the
four neighbourhood pages and the blog.

---

## 1. Phone number / button visibility
- Fixed the **"Call (416) 706-0727"** button in the hero (`.btn-ghost`) that had
  black text on a dark background — made the text visible.
- Added a stylesheet cache-busting version (`styles.css?v=…`) so browsers always
  load the latest CSS (bumped repeatedly through the session; currently `v=12`).

## 2. Hero stats
- Changed hero stats to **"5.0★ Average rating"** and **"250+ Cars detailed"**
  (previously 4.9★ and 1,200+ Vehicles detailed).

- Added a small **asterisk note** in the hero: *"Access to a standard power outlet
